# spbu-building-recognition-bot
Telegram-бот для распознавания зданий СПбГУ в Петергофе по фотографиям и поиска похожих изображений.

Ссылка на датасет: https://drive.google.com/drive/u/0/folders/1x-dlj2bsEiJPb8sJqCgFQDv12Pz7SyV0

Командный учебный проект по разработке Telegram-бота для распознавания зданий Санкт-Петербургского государственного университета в Петергофе с использованием методов машинного обучения и компьютерного зрения.

Бот принимает фотографию здания, определяет, к какому объекту она относится, и возвращает три наиболее похожих изображения из подготовленного датасета.

## Цель проекта

Разработать систему распознавания зданий университетского кампуса по фотографиям, объединяющую классификацию изображений с поиском визуально похожих объектов.

## Описание проекта

В рамках проекта собран датасет фотографий зданий СПбГУ в Петергофе, обучена модель классификации изображений на основе архитектуры **ResNet50** и реализован Telegram-бот для взаимодействия с пользователем.

Система распознаёт шесть категорий объектов:

- ПМ-ПУ;
- Физический факультет;
- НИИФ;
- Химический факультет;
- Шайба;
- Математико-механический факультет.

### Принцип работы

1. Пользователь отправляет фотографию здания Telegram-боту.
2. Изображение предварительно обрабатывается и передаётся нейросетевой модели.
3. Модель ResNet50 определяет наиболее вероятную категорию здания.
4. Из изображения извлекается вектор признаков (feature vector).
5. Для фотографий предсказанной категории вычисляется косинусное сходство с изображением пользователя.
6. Бот возвращает название распознанного объекта и три наиболее похожие фотографии из датасета с оценками сходства.
